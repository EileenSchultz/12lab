# 12 практика

За основу берется код из 11 практики.

Задание:
1) Создать сущность "пользователь".
2) У одного пользователя может быть много заметок, и не может быть заметки без пользователя.
3) Сделать CRUD методы управления пользователями и получение всех заметок конкретного пользователя.

CRUD методы покрыты тестами. 
Перед каждым тестом БД очищается.
